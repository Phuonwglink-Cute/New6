# HieuDev BlueBlack Premium V6 Final

Bản nâng cấp xanh đen premium, tối ưu cho điện thoại và GitHub Pages.

## Điểm nổi bật
- Avatar tròn chuẩn, không còn viền vuông
- Music Player với 5 track, đổi cover theo bài
- Contact cards neon premium, icon đẹp hơn
- Dự án nổi bật được làm lại cân đối hơn
- Loading, reveal, smooth scroll và mouse glow
- Responsive cho iPhone / Android / Desktop

## Chỉnh nhanh
- Sửa link, số tài khoản, bài hát, ảnh cover trong `assets/config.js`
- Playlist và icon đều được render từ cấu hình
